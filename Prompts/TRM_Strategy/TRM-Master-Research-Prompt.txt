# 4. TRM — ORIGINAL MODEL
------------------------------------------------------------

## Definition

TRM is the original cumulative-capital recursive allocation model.

Inputs:

S = reset/base amount

N = maximum number of consecutive losing rounds

Rule:

First investment:

B₁ = S

After a loss:

Bₙ₊₁ = 2 × Tₙ

where:

Tₙ = B₁ + B₂ + ... + Bₙ

Therefore:

B₁ = S

B₂ = 2S

B₃ = 2(3S)

B₃ = 6S

and so on.

For S = 5:

5 → 10 → 30 → 90 → 270 → 810 → 2430 → ...

## Closed-form derivation

Derive mathematically:

Tₙ = S × 3^(n-1)

For n >= 2:

Bₙ = 2S × 3^(n-2)

Required bankroll after N consecutive losses, including the next
allocation:

M = S × 3^N

## Example

S = $5

N = 10

Sequence:

65610

Total after 10 losses:

Next allocation:

Total bankroll required:

295,245

Verify:

5 × 3^10 = 295,245

# 6. TRM V2 — ACTUAL PORTFOLIO-LOSS-BASED MODEL
------------------------------------------------------------

TRM V2 is the more stock-market-specific version.

The main change:

TRM V2 does NOT assume the entire investment was lost.

Instead:

Calculate the ACTUAL monetary loss of the current portfolio.

Core calculations:

Current Market Value:

Market Value = Total Shares × Current Stock Price

Unrealized P/L:

Unrealized P/L = Market Value - Total Invested

If the position is losing:

Actual Loss = Total Invested - Market Value

Then:

Next Investment = Actual Loss × Multiplier

Default multiplier:

2

Therefore:

Next Investment = 2 × Actual Loss

# 11. PROBABILITY ANALYSIS
------------------------------------------------------------

Use probability theory rigorously.

For independent events:

p = probability of success

q = 1 - p

Probability of N consecutive losses:

P(N losses) = q^N

Probability of at least one win in N independent rounds:

P(at least one win) = 1 - q^N

Probability of exactly k wins in N rounds:

P(X = k) =
C(N,k) × p^k × q^(N-k)

Expected number of wins:

E[X] = Np

Expected number of losses:

E[L] = Nq

IMPORTANT:

Do not automatically assume that stock-market trade outcomes are
independent Bernoulli trials.

Use independent Bernoulli probability only for theoretical simulations
unless empirical evidence supports the assumptions.
